О проекте:

Bybit Signal Bot — это асинхронный крипто-бот для сканирования рынка на предмет торговых сигналов LONG/SHORT по 45+ USDT-парам на бирже Bybit (линейные фьючерсы). Работает на таймфрейме 15 минут, совмещает классическую техническую логику (Nadaraya-Watson Envelope + RSI) с ML-моделью (RandomForest), а найденные сигналы отправляет в Discord через вебхук с подробной карточкой (цена, RSI, границы канала, ATR, уверенность модели).
Бот умеет работать в двух режимах: только сигналы (по умолчанию) и автотрейдинг на демо-счёте Bybit.

Что может бот:
📈 Генерация сигналов
Одновременно мониторит 45+ ликвидных пар (ADA, DOGE, LINK, AVAX, ARB, SUI, TAO, WIF, 1000PEPE и др.)

Работает строго по закрытию 15-минутной свечи — без репейнта и ложных срабатываний на незакрытых барах

Комбинирует два независимых источника сигналов:

ML-модель (RandomForest) — предсказывает вероятность роста через 3 свечи вперёд, выдаёт сигнал при уверенности > 75%

Rule-based fallback (NW + RSI) — LONG при пробое нижней границы конверта + RSI < 30, SHORT при пробое верхней + RSI > 70

🧠 Машинное обучение
Автообучение модели на исторических данных (500+ свечей)

20+ признаков: returns, RSI с лагами, ATR, MACD-гистограмма, StochRSI, EMA-50, объёмные соотношения, положение относительно NW-конверта, корреляция с BTC

Автоматическое переобучение раз в час

Стандартизация признаков (StandardScaler) перед подачей в модель

🎨 Технический индикатор: Nadaraya-Watson Envelope
Non-repainting реализация — значения регрессии и границ не меняются задним числом

Настраиваемые параметры: bandwidth, multiplier, lookback

Гауссово ядро для сглаживания регрессии, оценка волатильности через взвешенную дисперсию остатков

🛡️ Риск-менеджмент
Автоматические SL и TP от волатильности (SL = 0.9×ATR, TP = 1.3×ATR)

Лимит на количество одновременных позиций (MAX_OPEN_POSITIONS = 5)

Подавление дубликатов сигналов по одному символу (настраиваемое окно)

Фиксированный размер позиции в USDT (по умолчанию $100)

💬 Уведомления в Discord
Rich-embed карточки с типом сигнала, символом, ценой, RSI, границами канала и ATR

🛠️ Инфраструктура

Retry-логика на rate limit (10006)

Логирование в файл и консоль
